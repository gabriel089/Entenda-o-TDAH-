# Entenda o TDAH - Protótipo

Protótipo React + Vite pronto para deploy no Vercel.

## Como rodar localmente

1. Instale dependências:

```bash
npm install
```

2. Rodar em dev:

```bash
npm run dev
```

3. Build para produção:

```bash
npm run build
```

## Deploy no Vercel

1. Crie uma conta em https://vercel.com
2. Clique em "New Project" → "Import" → selecione o repositório ou faça upload do projeto (zip).
3. Vercel detectará o projeto Vite e fará o deploy automaticamente.
